# livingdocs-mcp

An MCP server + CLI that keeps software documentation in permanent sync
with code, for both AI agents and humans. Documentation is derived from
code and updated by appending, never overwriting — every change is
traceable to the commit that caused it.

Status: early scaffold (Phase 0 of the build plan). Not yet published.

See `docgen-plugin-plan.md` for the full architecture rationale.
